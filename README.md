# Tech Internship Listings

Aggregated Summer 2027 tech internship listings, pulled daily from community
trackers, individual company career pages, and Built In Seattle, deduped into

## Sources

**Aggregated (data pulled directly, updated daily):**
- Community trackers: [SimplifyJobs/Summer2027-Internships](https://github.com/SimplifyJobs/Summer2027-Internships), [vanshb03/Summer2027-Internships](https://github.com/vanshb03/Summer2027-Internships), [speedyapply/2027-SWE-College-Jobs](https://github.com/speedyapply/2027-SWE-College-Jobs), [zapplyjobs/Internships-2027](https://github.com/zapplyjobs/Internships-2027)

- 36 companies' career pages directly, via their public/self-serve ATS APIs:
  - **Greenhouse:** Stripe, Databricks, Twilio, MongoDB, Roblox, Reddit, Instacart, Coinbase, Robinhood, Affirm, Chime, Brex, Point72, Anthropic, xAI, Scale AI, Together AI
  - **Ashby:** OpenAI, Confluent, Plaid, Ramp, Mistral AI, Cohere, Perplexity AI, Character.AI, Runway ML
  - **Workday:** NVIDIA, Salesforce, Adobe, Cisco, Zoom, Broadcom
  - **Eightfold:** Microsoft, Netflix, Qualcomm
  - **Workable:** Hugging Face

**Not aggregated, link out instead:**
- [LinkedIn Jobs](https://www.linkedin.com/jobs/) — `robots.txt` prohibits automated access
- [Runway](https://app.joinrunway.io/explore)
- [jobright.ai](https://jobright.ai/) — `robots.txt` specifically blocks AI crawlers from `/jobs/`

- Amazon, Meta, Google, Apple, IBM, Intel, Oracle, Uber, Snowflake, Goldman Sachs, JPMorgan Chase, Jane Street, Capital One, Two Sigma, Tesla, Waymo, HubSpot, Rippling, AMD, Arm — custom career-page systems with no public structured data (or, for a couple, active bot-blocking)
